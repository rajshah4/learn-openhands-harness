1. **`search` — SQL injection** (`service.py:6`): `owner` and `title` interpolated into the SQL string via f-string. An injected title (`' OR '1'='1' OR title='public`) returns every document, breaking the exact-title/owner guarantee. Contract: "Treat SQL punctuation literally."
2. **`read_doc` — missing owner authorization** (`service.py:8`): filters only on `id`, ignoring the `user` argument. Any caller can read any document; contract requires `(title,)` only for a matching owner and id, otherwise `None`.
3. **`read_export` — path containment bypass** (`service.py:11`): string-prefix test `str(target).startswith(str(root))` accepts a sibling directory sharing the prefix (`../exports_secret/...`), accepts external symlinks, and never rejects absolute names. Contract requires `PermissionError` for all three.

### Fixes (only `service.py` changed)
- `search` → parameterized query (`owner=? AND title=?`).
- `read_doc` → parameterized query with `owner=? AND id=?`.
- `read_export` → reject absolute names with `Path.is_absolute()`, then enforce containment via `target.relative_to(root)` (catches sibling-dir and symlink escapes).
- `safe_lookup` and `verify_signature` untouched (contract: not planted vulnerabilities).
