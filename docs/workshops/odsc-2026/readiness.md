# Workshop release readiness

The learning repository owns the student instructions, portable fixtures,
prompts, checks, and selected evidence. The harness-engineering repository
owns the talk and conceptual references and should link to this workshop.

## Included in this package

- One route through all six labs with preparation, prompt, check, and worksheet.
- Focused isolated starters; no instructor machine paths in executable prompts.
- Updated memory task and guidance with accepted design records.
- Four routing tasks, ordinary goal repair, and two delegation prompts.
- Read-only GitHub MCP with primitive, broad, and task-shaped modes.
- Selected historical receipts with explicit limitations and a facilitator key.
- Local package validation and site build instructions.

## Before students use the release

- Publish this branch and confirm the Pages deployment and every workshop route.
- Rehearse on a clean student machine using the installation instructions.
- Verify one available model across the intended harnesses and record versions.
- Rehearse native goals and delegation against the actual classroom Canvas/server.
- Confirm the MCP stdio configuration and API quota on that machine.
- Add selected behavioral traces for every offline comparison; current receipts
  do not include a full trace for every lane.
- Align the final slide prompts and links with these portable tasks.

No live model call or instructor-host run is claimed by local package checks.
Native goals and delegation still require classroom integration rehearsal.
