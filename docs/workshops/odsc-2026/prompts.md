# Exercise prompts

Use this page to open the workshop exercises in order. Each link goes directly to the task prompt or worksheet template in its exercise, where the code block has a copy button.

| Exercise | Open the prompt or template | Use it for |
|---|---|---|
| 1. Compare harnesses | [Pagination repair and CLI feature](/workshops/odsc-2026/exercises/00-working-harness#use-one-fast-task) | Run the same task through OpenHands, Pi, and OpenCode. |
| 2. Compare tool access | [GitHub investigation prompt](/workshops/odsc-2026/exercises/01-add-harness-capability#start-with-github-mcp) | Compare tool configurations while keeping the task fixed. |
| 3. Choose context | [Cursor pagination task](/workshops/odsc-2026/exercises/02-place-context#compare-three-agents) | Compare which instructions and context reach the agent. |
| 4. Route models | [Routing policy template](/workshops/odsc-2026/exercises/03-model-routing#write-a-routing-policy) | Record your policy after inspecting the routing experiment. |
| 5. Define completion | [Goal alternatives](/workshops/odsc-2026/exercises/04-let-it-run#write-the-goal) and [execution contract](/workshops/odsc-2026/exercises/04-let-it-run#write-the-long-running-contract) | Choose a goal and define what counts as done. |
| 6. Delegate work | [Delegation policy template](/workshops/odsc-2026/exercises/05-multi-agent#write-a-delegation-policy) | Define roles, boundaries, handoffs, and budget. |
| Optional long project | [Incident-system lab](/workshops/odsc-2026/long-project) | Run the complete benchmark from its starter project. |

Read the exercise's setup before sending a task prompt. Task prompts go into Canvas; policy templates and goal alternatives are discussion material to complete in the [workshop worksheet](/workshops/odsc-2026/worksheet).

For local runs, use the exercise's starter files and a fresh conversation. Use separate workspaces for editing agents, and install the exercise's test dependencies before timing the run. You can use free OpenHands Cloud models or your own models; record the actual model and agent when comparing results.

Need to install Canvas or configure a model? Start with [Get started for the workshop](/workshops/odsc-2026/setup).
