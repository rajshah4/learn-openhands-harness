New implementation exercise; stubs deliberately incomplete. Implement codec.py encode(fields) and decode(line), reducer.py summarize(lines). fields is a list of strings, length >=1. Encode joins fields with | and escapes backslash as \\ and pipe as \|. decode reverses this, preserves empty and Unicode fields, and raises ValueError for a trailing backslash or an escape other than backslash or pipe. Empty line decodes to ['']. summarize consumes iterable encoded records [event_id, account, signed_integer_cents]. Each record has exactly 3 fields, cents matches optional minus sign followed by one or more ASCII digits (leading zeros allowed, + disallowed). Account and ID may be empty or contain escaped delimiters. Exact retransmissions (same decoded ID/account/integer cents) count once. Conflicting duplicate IDs raise ValueError. Malformed encoding, field count or cents raises ValueError. Return dict account -> summed integer cents, retaining zero totals; empty input -> {}. Use codec.decode in reducer. Do not mutate input. Only codec.py, reducer.py, test_ledger.py may change. No dependency installs.
