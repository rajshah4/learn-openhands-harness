# Daily report acceptance contract
Input transactions.csv has id, amount, status. Include only status=posted; pending rows do not count. Amounts are exact decimal cents, may be negative, and must not be summed as binary floats. Duplicate IDs are exact retransmissions and count once. Output report.json must contain total as a two-decimal STRING and rows as the number of included unique posted transactions. Produce reconciliation.json with included_ids (sorted), excluded_pending_ids (sorted unique), duplicate_ids (sorted unique across the input), and total matching report.json. Running python3 report.py must produce both artifacts. Empty input (header only) produces total 0.00, rows 0, and empty ID lists. Keep build(source,destination) callable; write reconciliation.json beside destination. No dependency installs. No extra files beyond the two artifacts and allowed source/test files.
