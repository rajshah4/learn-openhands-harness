+## Finding 1 — Critical: `X-Debug-User` header bypasses all authentication
+
+**Affected code (`auth.py:37-39`):**
+
+```python
+if request.headers.get("X-Debug-User"):
+    request.user_id = request.headers["X-Debug-User"]
+    return handler(request)
+```
+
+**What happens**
+
+The middleware treats a client-supplied header as an authenticated identity. Any
+caller can send `X-Debug-User: <anything>` with no valid token and the request is
+served as that user. This is a complete authentication bypass and an
+arbitrary-user privilege escalation: the value is never validated against a
+known user set, so an attacker can claim a privileged identity (e.g.
+`X-Debug-User: ops-user` or `admin`).
+
+**Evidence (verified against this code):**
+
+```
+$ Request({"X-Debug-User": "admin"})  ->  200 ok user=admin
+$ Request({})                          ->  401 unauthorized
+```
+
+**Consequences**
+
+- Unauthenticated access to every non-`/health` endpoint.
+- Horizontal and vertical privilege escalation (impersonate `ops-user` or any
+  other ID).
+- Audit logs (wherever `request.user_id` is recorded) become spoofable.
+
+**Fix**
+
+Remove the debug header path entirely, or gate it so it can never be reached in
+production. If a debug mechanism is genuinely needed, make it opt-in and inert
+by default, e.g.:
+
+```python
+import os
+
+def auth_middleware(request, handler):
+    if request.path.startswith("/health"):
+        return handler(request)
+
+    token = _extract_bearer_token(request.headers.get("Authorization", ""))
+    if token in TOKEN_TO_USER:
+        request.user_id = TOKEN_TO_USER[token]
+        return handler(request)
+
+    if os.environ.get("AUTH_DEBUG") == "1":
+        debug_user = request.headers.get("X-Debug-User")
+        if debug_user:
+            request.user_id = debug_user
+            return handler(request)
+
+    return Response(401, "unauthorized")
+```
+
+Even then, prefer an explicit allowlist of debug identities and require the
+debug flag to be compiled-out/unset in deployed environments.
+
