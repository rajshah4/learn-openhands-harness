# Decision 002: one pagination boundary, one resume protocol
Status: accepted; supersedes 001. This workshop history is simulated.

The report exporter is now a second paging caller alongside catalog browsing.
Keep paging result types and implementations together in toyapp.pagination:
export_window and ExportWindow have moved there. Package __init__.py is empty;
consumers import from the owning module. The exporter is a real caller and its
regression tests exercise traversal, bounds and token validation.

Decimal offsets leaked the wire representation to callers. Shared helpers in
toyapp.tokens now encode opaque, canonical URL-safe base64 without padding,
with payload v2:<zero-based offset>. decode_offset rejects malformed tokens,
wrong versions, negative offsets and noncanonical encodings with ValueError.
The exported functions preserve caller-supplied ordering; they do not sort or
mutate the source. These are snapshot offsets, not stable database cursors.

The existing one-based paginate and Page contract remains public. Adding a new
paging caller must preserve both existing callers. Extend test_pagination.py
for focused tests, then run python3 -m pytest -q for caller regressions. Keep
frozen dataclasses, type hints and simple functions; no new dependency is needed.
# Decision 003: next-page catalog browsing
Status: accepted; builds on 002. This workshop history is simulated.

Add CursorPage and paginate_cursor to toyapp.pagination. CursorPage is a frozen
generic dataclass with items: list[T], next_cursor: str | None, has_more: bool.
Signature: paginate_cursor(items, cursor=None, per_page=20). Reuse the existing
shared v2 token protocol; next_cursor points to the first item of the next page.
It is None at the end, including empty input and a valid offset beyond the end.
has_more is true exactly when next_cursor is not None. Reject per_page < 1 and
invalid cursors with ValueError. Preserve ordering and do not mutate inputs.

Add browse_next(items, cursor=None, per_page=20) in toyapp.catalog as a thin
caller of paginate_cursor. Existing browse, paginate, page_numbers, exports and
their validation remain unchanged. Public consumers import the new API from
toyapp.pagination and toyapp.catalog; no package-root re-exports are required.
The current implementation and tests for exports are the sibling feature to
learn from. Focused cursor tests and the full suite cover different contracts.

import base64
import binascii
import re


def encode_offset(offset: int) -> str:
    return base64.urlsafe_b64encode(f"v2:{offset}".encode()).decode().rstrip("=")


def decode_offset(cursor: str | None) -> int:
    if cursor is None:
        return 0
    if not isinstance(cursor, str) or not re.fullmatch(r"[A-Za-z0-9_-]+", cursor):
        raise ValueError("invalid resume token")
    try:
        raw = base64.b64decode(cursor + "=" * (-len(cursor) % 4), altchars=b"-_", validate=True).decode("ascii")
    except (binascii.Error, UnicodeError, ValueError) as exc:
        raise ValueError("invalid resume token") from exc
    if not re.fullmatch(r"v2:[0-9]+", raw):
        raise ValueError("unsupported resume token")
    offset = int(raw[3:])
    if encode_offset(offset) != cursor:
        raise ValueError("noncanonical resume token")
    return offset
